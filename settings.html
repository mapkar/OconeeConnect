MeshCore settings

The radio plan for this county mesh

These are the settings that let your node hear (and be heard by) the rest of OconeeConnect. Flash steps are on the Connect page.

Preset USA/Canada (Recommended) · Frequency 910.525 MHz · Bandwidth 62.5 kHz · Spreading Factor 7 · Coding Rate 5 · handhelds Companion · fixed sites Repeater.

How a message hops

  1. Each person has a node running Companion firmware.
  2. Your phone connects over Bluetooth (or USB).
  3. A text goes out over 915 MHz LoRa on the USA/Canada preset.
  4. Nearby MeshCore repeaters on the same radio settings rebroadcast it.
  5. Location can ride along if configured.

Channels and roles

  • The public channel is the default place to meet. Don't put secrets on it.
  • You can add private channels or direct messages as needed.
  • Handhelds and personal nodes use Companion firmware (they do not rebroadcast by default).
  • Fixed high sites use Repeater firmware so they can extend the mesh.

Position and map

Position is optional. Use the app map to set a general location if you want to appear on the public map. A node sitting in a drawer does not need a precise pin.

If you still have Meshtastic on a board

Just reflash MeshCore (and erase first). Meshtastic will not exchange messages with this mesh. Official docs and tools: meshcore.io.
