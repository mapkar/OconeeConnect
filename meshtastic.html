Meshtastic guide

The other firmware on the same radios

Meshtastic is the older, more common LoRa messenger in the US. You flash a board, open the app, and nearby Meshtastic nodes help carry the message. It is excellent for a hike, a ballgame, or a neighborhood that has not built dedicated repeaters yet.

A Meshtastic node cannot message a MeshCore node over the air. OconeeConnect’s planned county backbone is MeshCore. Keep Meshtastic if that is the group you actually talk to. Switch firmware if you want the OconeeConnect backbone.

How Meshtastic hops

  1. Each person has a node.
  2. Phone connects over Bluetooth.
  3. A text goes out over 915 MHz LoRa.
  4. Nearby Meshtastic nodes rebroadcast it (managed flooding).
  5. Location can ride along if the board has GPS.

Join a Meshtastic mesh

  1. Same 915 MHz hardware as the radios page.
  2. Flash from Chrome/Edge at flasher.meshtastic.org. Latest stable.
  3. Install the Meshtastic app (Play Store, App Store) or use client.meshtastic.org.
  4. Settings → LoRa → Region → US.
  5. Preset LongFast is the usual public starting point.

Public LongFast uses a well-known default key. Anyone on that preset can read the public channel. Use a secondary channel with a private key for family or team traffic.

Local Meshtastic reality

Upstate SC already has Meshtastic users. Search MeshMap.net and local Facebook groups. That activity is useful — it is just not the same network as the MeshCore hubs described on Coverage.

Official docs: meshtastic.org
