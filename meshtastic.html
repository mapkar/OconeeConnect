Meshtastic settings

The radio plan for this county mesh

This is the OconeeConnect network, not a side firmware. Flash steps are on Connect. These are the numbers that make a node audible.

Region US · preset LongFast · frequency slot 20 · hop limit 3 · handheld role CLIENT.

How a message hops

  1. Each person has a node.
  2. Phone connects over Bluetooth.
  3. A text goes out over 915 MHz LoRa.
  4. Nearby Meshtastic nodes on the same channel rebroadcast it, up to the hop limit.
  5. Location can ride along if the board has GPS and the channel allows it.

Channels

  • Primary stays the public LongFast channel until a household QR is published. The default key is public. Do not put secrets on it.
  • Add a secondary channel with a private key for family or a route crew.
  • South Carolina Mesh publishes an optional secondary named SCMesh for the wider state map. Use their current join page at scmesh.us if you want that. It is not required to hear a local Oconee node.
  • Do not rename the primary and leave the frequency slot at 0. The slot is hashed from the name. Set slot 20.

MQTT and position

MQTT is optional and is not the mesh. If you uplink, leave encryption enabled and coarsen position. Map reports are unencrypted by design. A node in a drawer does not need a 10-meter map pin.

If you still have MeshCore on a board

Reflash Meshtastic and erase first. MeshCore will not exchange messages with this mesh. Official docs: meshtastic.org.
